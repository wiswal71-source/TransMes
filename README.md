## الحصول على ملف APK بدون حاسوب (عبر GitHub مجاناً)
1. أنشئ حساباً على github.com ثم مستودعاً جديداً (Repository) باسم TransMes.
2. ارفع محتويات هذا المجلد كما هي (Add file → Upload files) — تأكد أن مجلد .github مرفوع أيضاً.
3. من تبويب Actions اختر "Build APK" ثم Run workflow.
4. بعد 4-6 دقائق نزّل ملف TransMes-APK من قسم Artifacts، داخله app-debug.apk — ثبّته على هاتفك.

---
# TransMes - Offline SMS Translator

تطبيق أندرويد يترجم الرسائل النصية الواردة تلقائياً بشكل أوفلاين (بعد تحميل الموديل مرة واحدة).

## المميزات
- ترجمة أوفلاين باستخدام Google ML Kit
- ترجمة كل الرسائل الواردة تلقائياً
- واجهة بسيطة
- إشعارات بالترجمة
- اختيار اللغة المستهدفة
- حفظ الرسائل المترجمة

## طريقة البناء (مهمة جداً)

1. افتح **Android Studio**
2. اختر **Open** وحدد مجلد `TransMes`
3. انتظر حتى ينتهي Gradle Sync (قد يطلب تحميل بعض الملفات)
4. إذا ظهر خطأ بخصوص الأيقونات، اضغط بزر الماوس الأيمن على مجلد `app` → New → Image Asset واصنع أيقونة بسيطة
5. اذهب إلى القائمة:
   **Build → Build Bundle(s) / APK(s) → Build APK(s)**
6. بعد انتهاء البناء ستجد الملف هنا:
   `app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات مهمة
- أول مرة يترجم فيها التطبيق سيحتاج إنترنت لتحميل موديل اللغة (مرة واحدة فقط).
- يجب منح صلاحيات قراءة واستقبال الرسائل عند أول تشغيل.
- حالياً مصدر الترجمة مفترض أنه إنجليزي. يمكن تحسينه لاحقاً بإضافة كشف اللغة التلقائي.

## التطوير المستقبلي المقترح
- إضافة Language Identification لكشف لغة الرسالة تلقائياً
- دعم المزيد من اللغات
- ترجمة الرسائل القديمة أيضاً
